06为什么这些数字可信

  1. 六合约全自有、代币源码已验证。 MURMUR 代币在 Arc 浏览器完成源码确权，带官方识别图标，无匿名代币风险。
  2. 每笔结算都是链上真实转账。 EIP-3009 授权 + reveal 转账在 Arc 挖出；回执哈希链的链头经 NeuralReceiptRegistry 提交上链，可在浏览器逐笔回溯。
  3. 回执正文钉存 IPFS。 每个已挖出回执附带 CID——任何人可取回正文、复算哈希、与链上 nonce 对账，无须信任任何服务器。
  4. 收款地址唯一且公开。 全部资金路径（结算、金库、费用）汇入同一 ADMIN 地址，一条钱包线索审计一切。
  5. 数字全部公开可复算。 /telemetry、/history、/proofs、/openapi.json 无鉴权开放；编年史逐行可在浏览器内确定性重导，无 LLM 参与写作。

07诚实的局限

  1. 所有数字是测量，不是估计。 没有样本时显示"—"而不是 0；样本数随每个指标一起公布。
  2. 延迟只统计成功结算。 失败尝试的耗时混入退避与重试噪音，不代表读者实际会付出的结算成本；延迟环为最近 64 笔已挖出净扎，随基础设施重启持久保留。
  3. 轨道状态如实披露。 facilitator 未注资时结算尝试按预期失败（01 区琥珀条说明）；注资后本页自动点亮，无需任何人工干预。
  4. 本页不构成投资建议。 24 只代理规模的基尼系数是社会实验观察值，不是财富分配结论；请以 Arc 浏览器链上数据为最终对账依据。
